### 🔎 [Peek](https://github.com/lgubala/Peek)
![MIT](https://img.shields.io/badge/MIT-blue?label=license) ![Chrome | Firefox](https://img.shields.io/badge/Chrome%20%7C%20Firefox-grey)

Hover any link and Peek shows what's actually behind it — a recipe's ingredients, an article's text, a product's price, or a GitHub README — plus where the domain is registered and whether it looks deceptive, before you ever click.

### 🐾 [Ruckus](https://github.com/lgubala/Ruckus)
![MIT](https://img.shields.io/badge/MIT-blue?label=license) ![Chrome | Firefox](https://img.shields.io/badge/Chrome%20%7C%20Firefox-grey)

A pixel creature that lives in your browser, wanders your pages, and doubles as a prettier `Ctrl+F`, an offline PDF/Word toolkit, and a place to bury pages for later. No network code at all.

### 🗣️ [Lingo Loco](https://github.com/lgubala/LingoLoco)
![MIT](https://img.shields.io/badge/MIT-blue?label=license) ![Chrome | Firefox](https://img.shields.io/badge/Chrome%20%7C%20Firefox-grey)

The web only really knows fifty words — *seamless*, *doubling down*, *unlocks value at scale*. Lingo Loco quietly rewrites them as you read, on rules you write yourself.

### 🕵️ [SpyCheck](https://github.com/lgubala/SpyCheck)
![GPL-3.0](https://img.shields.io/badge/GPL--3.0-blue?label=license) ![Android](https://img.shields.io/badge/Android-3DDC84)

An educational Android app that demonstrates, hands-on, how apps track users and collect data — GPS extraction, WiFi location, clipboard snooping — to raise privacy awareness.
